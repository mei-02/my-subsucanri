# my-subsucanri

自分専用のサブスク管理アプリです。スマホのホーム画面に追加して使う Web アプリ（PWA）です。

公開URL: https://mei-02.github.io/my-subsucanri/

## できること

- ホームは貯金箱。開くたびにサブスクのアイコンが降ってきて底に積もる（大きさ＝料金、重ならない）
- 月ごとのカレンダーで、いつ・いくら払うかをアイコン表示／金額表示で確認
- よく使われる約45サービスとそのプランを内蔵。複数まとめて選んで登録できる（料金は2026年10月時点の参考価格）
- サブスクごとに ID・パスワード・料金・支払方法・支払いサイクルを登録
- 月払い／年払い／数ヶ月ごと／週払い、無料トライアル、ドル建てに対応
- 毎月の合計・契約開始からの累計を自動で計算、カテゴリ別・支払方法別の内訳と節約記録
- サービスのアイコン（主要サービスは内蔵。ないものは画像の登録か、ボタンを押したときだけ自動で取得）

## データの扱い

- データはすべて端末の中（IndexedDB）に、マスターパスワードで暗号化して保存します（PBKDF2 + AES-GCM）
- サーバーには何も送りません。例外は「アイコンを自動で取得」ボタンを押したときで、入力したドメイン名だけを外部のアイコン取得サービスに送ります
- マスターパスワードを忘れるとデータは復元できません
- 10分操作しないと自動でロックします
- 機種変更に備えて、設定画面から暗号化したバックアップファイルを書き出せます

## 開発

```sh
npm install
npm run dev     # http://localhost:5173/my-subsucanri/
npm test        # 計算と暗号化のテスト
npm run build
```

開発中は、データが空のとき設定画面に「サンプルデータを入れる」ボタンが出ます。

## 公開

`main` ブランチに push すると GitHub Actions がビルドして GitHub Pages に公開します。
初回だけ、リポジトリの Settings → Pages → Build and deployment の Source を「GitHub Actions」にしてください。
